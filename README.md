# chameleon-data

An interactive CLI for fake data generated by [Faker](https://faker.readthedocs.io/): it replaces selected columns of a CSV / TSV / XLSX file (saved in the same format as the input), or generates test data from scratch (CSV / TSV / XLSX / JSON).

## Installation

Published on PyPI as [`chameleon-data`](https://pypi.org/project/chameleon-data/). Requires Python 3.11 or later.
After installation, the `chameleon` command is available.

### uv

```bash
# Install as a global CLI tool (recommended)
uv tool install chameleon-data

# Run once without installing
uvx --from chameleon-data chameleon mask -f data.csv

# Add as a dependency of another project
uv add chameleon-data

# Install into the current virtual environment
uv pip install chameleon-data
```

Upgrade / uninstall:

```bash
uv tool upgrade chameleon-data
uv tool uninstall chameleon-data
```

### pip

```bash
pip install chameleon-data

# Upgrade / uninstall
pip install --upgrade chameleon-data
pip uninstall chameleon-data
```

To use it as a standalone CLI without touching other environments, [pipx](https://pipx.pypa.io/) works too:

```bash
pipx install chameleon-data
```

### From GitHub (development version)

```bash
uv tool install git+https://github.com/hidariutiwa/chameleon-data
pip install git+https://github.com/hidariutiwa/chameleon-data
```

To pin a specific version, use `git+https://github.com/hidariutiwa/chameleon-data@<tag or commit>`.

## Usage

| Command | Description |
| --- | --- |
| `chameleon mask` | Mask columns of a file with fake data |
| `chameleon generate` | Generate test data with fake values |
| `chameleon example` | Write a sample file to `./example/example.csv` |

`chameleon -v` shows the version, and `chameleon <command> -h` shows the options of each command.

### mask

```bash
chameleon mask -f data.csv                 # saves to data_masked.csv
chameleon mask -f data.xlsx -o out.xlsx    # specify the output path
chameleon mask -f data.tsv -l en_US -s 42  # specify locale and seed
```

| Option | Description |
| --- | --- |
| `-f`, `--filepath` | Input file (required). `.csv` / `.tsv` / `.xlsx` |
| `-o`, `--output` | Output file. Defaults to `<filename>_masked.<suffix>` |
| `-l`, `--language` | Faker locale. Defaults to `ja_JP` |
| `-s`, `--seed` | Random seed. Set it to get the same result every time |

When run, you pick the columns to mask with a checkbox prompt (each column is shown with up to three of its values, so you can see what it holds), then choose a replacement type for each column. Each type is shown with a sample value (with a Japanese name alongside for `ja` locales), and you can type to filter the list.

| Group | Types |
| --- | --- |
| — | `masking`: every character becomes `*` (length is kept) |
| person | `full_name` / `first_name` / `last_name`, `full_name_kana` / `last_name_kana` / `first_name_kana`, `email`, `user_name`, `date_of_birth`, `age`, `phone_number` |
| address | `full_address`, `address_below_city`, `zipcode`, `prefecture`, `city`, `street`, `building` |
| business | `company`, `job`, `url`, `domain`, `ipv4`, `ipv4_private` |
| finance / id | `credit_card_number`, `credit_card_expire`, `credit_card_security_code`, `bank_account`, `iban`, `uuid`, `passport_number`, `number`, `date` |

Types the locale does not support (e.g. kana names and `building` outside `ja_JP`) are hidden from the list.

Identical values are replaced with identical fake values, so relationships between rows are preserved. Empty cells stay empty.

### generate

```bash
chameleon generate                          # enter column names, saves 100 rows to fake_data.csv
chameleon generate -f data.csv -n 1000      # columns from the header row of data.csv, saves to data_fake.csv
chameleon generate -f data.xlsx --format json  # saves to data_fake.json
chameleon generate -o out.tsv -s 42         # the suffix of -o decides the format
```

| Option | Description |
| --- | --- |
| `-f`, `--filepath` | File whose header row gives the columns (only the header is read). `.csv` / `.tsv` / `.xlsx`. Without it, you enter column names one by one (empty input finishes) |
| `-o`, `--output` | Output file; its suffix decides the format. Defaults to `<filename>_fake.<format>`, or `fake_data.<format>` in the current directory without `-f` |
| `-n`, `--rows` | Number of rows (1 or more). Defaults to `100` |
| `--format` | `csv` / `tsv` / `xlsx` / `json`. Defaults to `csv`, or the suffix of `-o`. Must match `-o` when both are given |
| `-l`, `--language` | Faker locale. Defaults to `ja_JP` |
| `-s`, `--seed` | Random seed. Set it to get the same result every time |

You choose a type for every column from the same list as `mask` (without `masking`). When two or more name types are used, each row describes one person (`full_name` is `last_name` + `first_name`, and kana match the kanji). JSON is written as an array of records:

```json
[
  {
    "first_name": "篤司",
    "last_name": "山崎"
  }
]
```


### Migrating from v0.4

The v0.4 commands still work in v0.5 but print a deprecation warning, and will be removed in v0.6.0.

| v0.4 | v0.5 and later |
| --- | --- |
| `chameleon -f data.csv ...` | `chameleon mask -f data.csv ...` |
| `chameleon-example` | `chameleon example` |

## Development

Uses [uv](https://docs.astral.sh/uv/).

```bash
uv sync
uv run chameleon mask -f example/example.csv
uv build   # builds a wheel and sdist into dist/
```

### Release

Pushing a `v*` tag triggers GitHub Actions (`.github/workflows/publish.yml`), which publishes to PyPI via Trusted Publishing.

```bash
uv version --bump patch   # bump the version in pyproject.toml (minor / major also work)
git commit -am "chore: release v$(uv version --short)"
git tag "v$(uv version --short)"
git push origin main --tags
```
